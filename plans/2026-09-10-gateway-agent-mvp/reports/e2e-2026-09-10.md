## Known environment gaps (not code defects)

1. **`rg` (ripgrep) not installed** on this machine/PATH. `code_search` correctly returns `INTERNAL_ERROR` when the binary can't be spawned — this is the sample README's own stated requirement ("ripgrep (`rg`) trong `PATH`"), not something this project should silently work around. Install ripgrep and `code_search` will work as implemented.
2. **`test_run`** failed in this specific test run because the smoke-test harness invoked `code-agent start` with a trimmed `PATH` that didn't include `pnpm`. In a normal user terminal (where `pnpm` is already on `PATH`), this will work — the failure mode itself (clean non-zero exit code + stderr surfaced back through MCP) proves the error path is correct.
